# Auto 本机 Responses 路由

为 AstrBot 提供固定的本机 Responses 接口，在上游模型不可用时自动重新选择并切换，减少手动修改模型配置。

适合上游 API 地址和密钥不变，但切换分组后可用模型名称会变化的场景。正常请求直接转发；调用失败后查询模型列表并重新选择。当前版本使用一个上游 API，不提供多 API 轮询、负载均衡或自动比价。

## 安装

要求 AstrBot `>=4.28.2,<5`，已在 4.29.0 验证。上游需要支持 OpenAI 兼容的 `/v1/models` 和 `/v1/responses` 接口。

在 AstrBot 插件管理中，通过以下仓库地址安装：

```text
https://github.com/ww1579532468/astrbot_plugin_auto_model
```

也可从 [Releases](https://github.com/ww1579532468/astrbot_plugin_auto_model/releases) 下载 ZIP，解压到插件目录后加载。

插件固定监听 `127.0.0.1:80`，需要该端口空闲，且运行 AstrBot 的账户具有绑定权限。Linux 使用 systemd 时，可在 AstrBot 服务中增加：

```ini
[Service]
AmbientCapabilities=CAP_NET_BIND_SERVICE
```

修改服务配置后需重新加载 systemd 并重启对应服务。服务名以自己的安装为准。Docker 部署需要 AstrBot 进程具备相应权限；这里的 `127.0.0.1` 指 AstrBot 所在容器，不是宿主机。

## 配置

| 配置项 | 说明 |
| --- | --- |
| 当前模型 | 实际转发使用的上游模型名。可留空，由首次请求选择；切换后自动保存，重启保留。 |
| API | 上游基础地址，例如 `https://example.com/v1`，不要填写完整的 `/responses` 地址。 |
| key | 上游 API 密钥。 |
| 优先级 | 每行一个模型名称，按从上到下的顺序精确匹配。可用 `模型名称|上下文长度` 指定长度，省略时默认 `100000`。 |

优先级示例，名称请替换为自己上游实际提供的模型：

```text
model-a|100000
model-b|190000
model-c
```

优先级可以留空。全部未匹配时，自动过滤明显绘图、非对话和高消耗思考模型，优先选 Flash 中数字版本最高的，其次选 Low 中数字版本最高的，最后选剩余列表中的最后一个。自动选出的模型会追加到优先级末尾。规则集中在 `main.py` 顶部。

手动优先级不受自动过滤限制；名称区分大小写。名称规则不能保证模型的接口兼容性或实际价格，请按上游说明填写。

## 使用

加载后通过 AstrBot 的配置服务和供应商管理器自动注册本机 Responses 供应商与模型。通常选择供应商 `auto` 下的模型即可；已有模型会沿用。

如需手动配置，使用 **OpenAI Responses** 类型：

| 项目 | 值 |
| --- | --- |
| 基础地址 | `http://127.0.0.1/v1` |
| 密钥 | `auto`，用于满足客户端必填项，本机接口不校验密钥 |
| 模型名 | 任意非空名称，例如 `auto` |
| 代理 | 留空，确保本机请求不走代理 |
| 上下文 | 默认 `100000`，可按需要在 AstrBot 中手动调整 |

接口为 `GET /v1/models`、`POST /v1/responses`，支持非流式和 SSE。请求里的模型名作为别名，实际转发统一使用“当前模型”；响应保留上游的实际模型名。

## 运行行为

- 正常调用不查询模型列表，也不主动切回优先级更高的模型。
- 调用失败后获取一次可用模型列表；只有选出了不同模型，才重试一次。仍选中原模型、没有可用模型或查询失败时返回错误，不遍历所有模型。
- 缓存写入插件配置，不因插件重载或服务重启清空。日志仅记录模型切换。
- SSE 开始后不再重试，流内错误事件由客户端处理。
- 模型列表查询最多 15 秒、响应最多 4 MiB；非流式会话响应最多 32 MiB。插件不设置会话总超时，由 AstrBot 或调用方控制。
- `/models` 的 `context_window` 提供当前上下文信息，但不会自动修改 AstrBot 已注册模型的上下文设置。

接口仅对 AstrBot 所在主机或容器的本机进程开放，不提供外网访问。若没有自动注册成功，可查看 `/v1/models` 中的 `registration_error`，并核对 AstrBot 版本及已有 `auto` 供应商的类型和地址。
